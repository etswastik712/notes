# Conjugacy Class

> [!info] Source
> Kurzweil–Stellmacher; written up in [[GT05 Actions Conjugation and Sylow Theorems]].

> [!intuition] In one picture
> The orbit of $x$ under conjugation; size $|G:C_G(x)|$.

> [!key] Key facts
> - Classes of $S_n$ = cycle types.
> - $S_4$: sizes 1, 3, 6, 6, 8; $A_5$: 1, 12, 12, 15, 20.
> - Columns of a character table = classes.

Used in: [[GT05 Actions Conjugation and Sylow Theorems]]. Related: [[Class Equation]] · [[Character Table]].
