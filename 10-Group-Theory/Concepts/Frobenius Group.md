# Frobenius Group

> [!info] Source
> Kurzweil–Stellmacher; written up in [[GT06 Permutation Groups]].

> [!intuition] In one picture
> A transitive group in which no non-identity element fixes more than one point (and some element fixes one).

> [!key] Key facts
> Kernel $K$ of fixed-point-free elements plus 1 has exactly $n$ elements (counting lemma) and is a normal subgroup (Frobenius's theorem): $G=K\rtimes H$. $S_3,A_4,F_{20},AGL(1,q)$.


Used in: [[GT06 Permutation Groups]]. Related: [[Semidirect Product]] · [[Transitive Action]].
