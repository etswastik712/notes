# Interactive Tools

> [!abstract] 100 self-contained interactive visualisations across 15 subject groups
> Each tool is one HTML file in `Assets/interactive/` (no internet, no install): sliders, live plots, animations and step-through explorers built to give a *picture* of the idea. Open in a browser; every chapter that uses a tool shows its preview image and a link in an *Interactive* callout.

> [!tip] How to open them
> **In Obsidian** the preview image shows inline; click **▶ Open the tool in your browser** (relative link) or the absolute `file://` link. If Obsidian does not open the link, turn on *Settings → Files and links → Detect all file extensions* (then `Assets/interactive/*.html` become openable), or open the file from the file manager / `xdg-open Assets/interactive/<id>.html`.
> **Rebuild:** `.venv/bin/python -W ignore scripts/build_interactive.py` (builds + checks + previews), then `.venv/bin/python -W ignore scripts/embed_interactive.py` (refreshes the callouts and this note).

> [!warning] What the tools are and are not
> The tools are my constructions (🔵 extra · beyond): they illustrate and cross-check the chapter content, and every number printed in a *Try it* line was recomputed (chapter scripts or an independent integration) when the tool was built, but a tool is not a source. Where a tool states a textbook value it is the chapter's value; where it uses a simplification (e.g. a constant Shields number, the 2D Maxwell–Boltzmann gas, valence-only MO diagrams) the note under the tool says so.

## Conventions for new tools

- One file per tool in `scripts/interactive/tools/<id>.js`; first line `//META {title, desc, vault, chapters, tryit}`; shared library `lib.js` and `base.css`.
- Match the chapter's verified numbers (default slider values reproduce the worked example) and say so in the note under the tool.
- Give every tool a *Try it* line; keep controls few and labelled; dark/light themes follow the system.
- Rebuild and embed with the two commands above; the hub and callouts regenerate.
