## Must know
- Formal charge: $f = V - L - \tfrac12 P$ ($V$ valence electrons, $L$ lone-pair electrons, $P$ shared electrons). The preferred Lewis structure has the lowest formal charges, with negative charge on the more electronegative atom (Classroom: Lecture 1a).
- Formal charge exaggerates covalent character; oxidation number exaggerates ionic character ($[\mathrm{NO_3}]^-$ as $[\mathrm{N^{5+}}][\mathrm{O^{2-}}]_3$, N(V)).
- Octet-rule limits: incomplete octet (BeH2, BCl3), odd-electron (NO, NO2), expanded octet (PCl5, SF6).
- VSEPR basic shapes: 2 linear, 3 trigonal planar, 4 tetrahedral, 5 TBP, 6 octahedral, 7 pentagonal bipyramidal. Repulsion order lp/lp > lp/bp > bp/bp; lone pairs take larger (equatorial) sites; multiple bonds count as one region but occupy more space.
- Bond angles: CH4 109.5°, NH3 107°, H2O 104.5°. SF4: TBP basic shape, lone pair equatorial.
- Lone pairs on heavy elements are often stereochemically inert (s-orbital): $[\mathrm{SeF_6}]^{2-}$, $[\mathrm{TeCl_6}]^{2-}$ octahedral; $[\mathrm{XeF_5}]^-$ pentagonal planar. XeF6 is a distorted octahedron (Classroom: announcement 2026-08-14).
- VB: H2 wavefunction $\psi = \chi_A(1)\chi_B(2) + \chi_A(2)\chi_B(1)$; sp³ hybrids are 109.47° apart ($\cos\theta=-1/3$).
- Hybrid angle relation: $\cos\theta = S/(S-1) = (P-1)/P$. H2O: bonding hybrids 20% s / 80% p, non-bonding 30% s / 70% p, angle between them 115.37°.
- Bent's rule: more electronegative substituents prefer hybrids with less s character; in PClxF5−x the more electronegative substituent is axial.
- MOT: LCAO $\psi = c_A\chi_A + c_B\chi_B$, $\psi_\pm = \chi_A\pm\chi_B$ for H2; bonding = constructive interference, antibonding has a node between the nuclei. Heteronuclear: the more electronegative atom contributes more to bonding MOs.
- CO: HOMO (3σ) and LUMO (2π) both on C, so it binds metals through C (σ-donation, π-back-donation); bond enthalpy CO 1070 vs N2 946 kJ/mol.
- Arrhenius: an acid raises $[\mathrm{H_3O^+}]$, a base raises $[\mathrm{OH^-}]$; fails for CO2, NH3, CaO and non-neutral salts (Classroom: Acids and Bases Lecture 1).
- Brønsted–Lowry: acid = proton donor, base = proton acceptor; conjugate base = what remains after loss of H⁺.
- Lux–Flood: base = O²⁻ donor (basic anhydride), acid = O²⁻ acceptor (acid anhydride), e.g. CaO + SiO2 → CaSiO3.
- Lewis: acid = e⁻-pair acceptor, base = e⁻-pair donor.
- Aqua, hydroxo, oxo acids: where the acidic proton sits; oxo-acid strength rises with central-atom electronegativity and electron-withdrawing substituents (CCl3COOH > CH3COOH; O2SF(OH) > O2S(NH2)(OH)).
- BF3 < BCl3 < BBr3 in Lewis acidity, because of F→B 2p–2p π back-donation; SiI4 < SiBr4 < SiCl4 < SiF4.
- HSAB: hard acids bind F⁻ > Cl⁻ > Br⁻ > I⁻, soft acids the reverse; hard binds hard, soft binds soft; hard–hard is electrostatic (Madelung), soft–soft is covalent/dispersion.
- Diborane: 12 valence electrons, 4 terminal 2c–2e⁻ B–H bonds plus 2 bridging 3c–2e⁻ B–H–B bonds.
- Wade's rules: closo $n+1$, nido $n+2$, arachno $n+3$, hypho $n+4$ skeletal electron pairs; each BH gives 2 electrons, each extra H gives 1, charges counted; for ligand-free clusters skeleton electrons = $g - 2n$.
- Borazine B3N3H6: "inorganic benzene", B–N 1.436 Å, prone to addition (e.g. 3 Br2); dehydropolymerizes to BN on pyrolysis at 1200 °C.
- Cyclophosphazenes $(\mathrm{NPX_2})_n$: pπ–dπ (Dewar "island") bonding; heating (NPCl2)3 at 210–250 °C gives polyphosphazenes $[\mathrm{N{=}PR_2}]_n$.
- Midsem Q2(i) point: when HSAB is not named in the question, CH3NH2 was also accepted for 1 mark (Classroom: announcement 2026-10-08).
