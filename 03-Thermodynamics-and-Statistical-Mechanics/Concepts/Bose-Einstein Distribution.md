# Bose-Einstein Distribution

> [!info] Source
> Kardar §7.3; Pathria Ch. 5, 7; derived for one mode in [[SM05 The Grand Canonical Ensemble and Chemical Equilibrium]] §5; full theory SM08, SM13 (planned).

> [!intuition] In one picture
> A state can hold any number of bosons, each with the same Boltzmann weight: a geometric series that diverges as $\mu\to\varepsilon$.

> [!key] Key facts
> $\langle n\rangle=1/(e^{(\varepsilon-\mu)/k_BT}-1)$, from $\mathcal Z_{\rm mode}=1/(1-e^{-x})$; variance $\langle n\rangle(1+\langle n\rangle)$ (bunching); requires $\mu<\varepsilon_{\min}$; $\to e^{-x}$ for $x\gg1$; $\mu=0$ for photons.

> [!example] Values (recomputed)
> $x=0.5,1,2,5$: $1.541,\ 0.582,\ 0.157,\ 0.00678$.
