# Hybridization

The linear combination and interference of atomic orbitals of different angular momentum on the same atom to form directional hybrid orbitals. These hybrid orbitals maximize overlap amplitude along bonding directions, yielding stronger equivalent or symmetry-adapted bonds.

$$h_1 = s + p_x + p_y + p_z$$

$$h_2 = s - p_x - p_y + p_z$$

$$h_3 = s - p_x + p_y - p_z$$

$$h_4 = s + p_x - p_y - p_z$$
