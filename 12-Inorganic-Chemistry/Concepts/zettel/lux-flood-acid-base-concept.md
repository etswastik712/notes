# Lux-Flood Acid-Base Concept

An acid-base classification developed for non-protic, high-temperature molten oxide systems where an acid is an oxide-ion acceptor (acid anhydride) and a base is an oxide-ion donor (basic anhydride).

$$\text{MgO} + \text{CO}_2 \rightleftharpoons \text{MgCO}_3$$

$$\text{CaO} + \text{SiO}_2 \rightleftharpoons \text{CaSiO}_3$$

$$\text{NO}_3^- + \text{S}_2\text{O}_7^{2-} \rightleftharpoons \text{NO}_2^+ + 2\text{SO}_4^{2-}$$
