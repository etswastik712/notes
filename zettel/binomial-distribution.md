# Binomial Distribution

The distribution of the discrete random variable counting the total number of heads obtained across n mutually independent coin tosses where each toss independently yields a head with probability p; called Bernoulli when n = 1.

## Links
- example-of:: [[zettel/discrete-random-variable]] — The total count of successes in n independent coin tosses takes values in {0, 1, ..., n}, making it a discrete random variable
- equivalent-to:: [[zettel/sum-of-independent-bernoulli-trials-representation-of-binomial]] — The coin toss description corresponds to summing n independent Bernoulli(p) indicator variables
