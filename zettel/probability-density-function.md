# Probability Density Function

A non-negative integrable function associated with a continuous random variable that integrates to one over the real line and yields the probability of the variable belonging to any Borel-measurable subset.

$$f(x) \geqslant 0 \quad \text{for each } x \in \mathbb{R}$$

$$\int_{-\infty}^\infty f(x) dx = 1$$

$$P[a \leqslant X \leqslant b] = \int_a^b f(x) dx$$
