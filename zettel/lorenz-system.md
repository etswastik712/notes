# Lorenz System

A deterministic system of three coupled, non-linear ordinary differential equations originally formulated to model atmospheric convection between a lower heated boundary and an upper cooled boundary. For particular parameter values, it serves as a canonical model exhibiting sensitive dependence on initial conditions and chaotic behavior.

$$\frac{dx}{dt} = \sigma(y - x)$$

$$\frac{dy}{dt} = x(\rho - z) - y$$

$$\frac{dz}{dt} = xy - \beta z$$
