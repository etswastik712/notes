# Accident-Proneness Posterior Inference

A two-state risk classification model using Bayes' theorem to update the prior probability of an individual being accident-prone based on the observation of an accident occurring within a fixed observation period.

- contrasts-with:: [[zettel/bayes-rule-for-multiple-choice-guessing]] — Both apply two-state Bayes inversion to binary outcomes, but accident proneness conditions on an adverse event rate rather than a binary knowledge state
