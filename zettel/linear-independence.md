# Linear Independence

A property of a subset of vectors in a vector space where every finite linear combination summing to the zero vector has exclusively zero scalar coefficients.

$$a_1 v_1 + \dots + a_n v_n = 0 \implies a_1 = \dots = a_n = 0$$
