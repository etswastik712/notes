# Plane Wave Momentum Eigenstate

The complex exponential plane wave e^{ikx} is an exact eigenstate of the coordinate momentum differential operator -iℏ d/dx with eigenvalue ℏk, whereas a real standing wave cos(kx) is not an eigenstate because differentiation mixes counter-propagating components.

$$\hat{p}\psi_1 = -i\hbar(ik)e^{ikx} = \hbar k e^{ikx} = \hbar k \psi_1$$

$$\hat{p}\psi_2 = \frac{\hbar k}{2}(e^{ikx} - e^{-ikx})$$
