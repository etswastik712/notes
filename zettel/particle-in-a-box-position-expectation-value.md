# Particle in a Box Position Expectation Value

The expected value of coordinate position for a particle in the n-th eigenstate of an infinite well. By reflection symmetry of the probability density about the geometric midpoint of the well, the expectation value evaluates to half the box width.

$$\langle x \rangle_n = \frac{a}{2}$$

$$\langle x \rangle_n = \int_0^a \psi_n^*(x) x \psi_n(x) \, dx$$
