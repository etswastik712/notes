# Red Interflow Horizon

A distinct reddish, weathered sedimentary or palaeosol layer separating successive basaltic lava flows. It represents an extended quiescent hiatus in eruptive activity that allowed weathering and pedogenesis on the exposed flow top before burial by subsequent lava pulses.
