# Commutativity Criteria for Connected Lie Groups

For a connected Lie group $G$ with Lie algebra $\mathfrak{g}$, elements $\exp(tX)$ and $\exp(sY)$ commute for all $s, t \in \mathbb{R}$ if and only if $[X, Y] = 0$. Consequently, $G$ is abelian if and only if $\mathfrak{g}$ is abelian.

$$[X, Y] = 0 \iff \exp(tX)\exp(sY) = \exp(sY)\exp(tX)$$
