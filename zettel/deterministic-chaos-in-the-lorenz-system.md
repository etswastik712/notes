# Deterministic Chaos in the Lorenz System

A dynamical property where a fully deterministic nonlinear system displays trajectory evolution that is acutely sensitive to microscopic perturbations in initial states. Over extended integration intervals, this sensitivity causes macroscopic divergence across trajectories originating from nearly identical coordinates.
