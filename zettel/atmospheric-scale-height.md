# Atmospheric Scale Height

An exponential vertical pressure distribution model relating pressure at any altitude or depth to sea-level pressure using a characteristic vertical e-folding length scale. It enables pressure and density estimates away from reference levels.

$$P = P_0 e^{-z/H}$$

$$P = \rho R_d T$$
