# Kuratowski Ordered Pair

The standard set-theoretic construction representing an ordered pair (A, B) as the set containing the singleton {A} and the unordered pair {A, B}. This construction achieves coordinate asymmetry without requiring the Axiom of Regularity.

$$(A, B) := \{\{A\}, \{A, B\}\}$$
