# Spherical Harmonics

A complete orthonormal set of angular functions on the two-sphere forming simultaneous eigenstates of the orbital angular momentum operators L^2 and L_z.

$$Y_{l,m}(\theta, \phi) \propto P_l^m(\cos\theta) e^{im\phi}$$

$$\hat{L}^2 Y_{l,m}(\theta, \phi) = \hbar^2 l(l+1) Y_{l,m}(\theta, \phi)$$

$$\hat{L}_z Y_{l,m}(\theta, \phi) = \hbar m Y_{l,m}(\theta, \phi)$$
