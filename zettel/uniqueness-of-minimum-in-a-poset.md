# Uniqueness of Minimum in a Poset

If a partially ordered set admits a minimum element, then this element is unique.

## Links
- needs:: [[zettel/minimum-element-in-a-poset]] — The theorem establishes the uniqueness property specifically for minimum elements
- needs:: [[zettel/partial-order]] — The proof relies directly on the antisymmetry property of partial orders (if m1 <= m2 and m2 <= m1 then m1 = m2)
