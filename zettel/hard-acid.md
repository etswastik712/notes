# Hard Acid

A Lewis acid that forms more stable complexes with lighter, less polarizable donor atoms through predominantly ionic or dipole-dipole interactions. It binds halide ligands in the affinity order iodide < bromide < chloride < fluoride.

$$\text{I}^- < \text{Br}^- < \text{Cl}^- < \text{F}^-$$

$$\text{R}_3\text{P} \ll \text{R}_3\text{N}$$

$$\text{R}_2\text{S} \ll \text{R}_2\text{O}$$
