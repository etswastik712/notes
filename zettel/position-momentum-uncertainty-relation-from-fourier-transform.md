# Position-Momentum Uncertainty Relation from Fourier Transform

The structural property that sharply localizing a wave function in coordinate space requires broad wavenumber content in its Fourier transform, dictating the reciprocal spread relation Delta x * Delta p >= hbar / 2.

$$p = \hbar k$$

$$\Delta p = \frac{\hbar}{2\sigma_x}$$

$$\Delta x \Delta p = \frac{\hbar}{2}$$
