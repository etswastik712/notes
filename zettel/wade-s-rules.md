# Wade's Rules

An electron-counting classification system that correlates the number of skeletal electron pairs with the deltahedral cage architecture of borane, carborane, and cluster frameworks.

## Links
- needs:: [[zettel/deltahedron]] — Cluster geometries in Wade's rules are formally classified as complete or vertex-truncated deltahedra
- used-in:: [[zettel/zintl-compounds-and-clusters]] — Wade's electron-counting rules extend to ligand-free anionic main-group Zintl clusters by treating non-skeletal electrons as outward lone pairs
