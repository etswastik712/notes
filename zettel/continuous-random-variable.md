# Continuous Random Variable

A real-valued random variable whose cumulative distribution function is absolutely continuous everywhere, or equivalently, one whose probability over any measurable subset is given by the integral of a non-negative function.

$$P[X \in B] = \int_B f(x) dx$$

$$P[X = x] = F(x) - F(x-) = 0$$
