# Overall Phase vs Relative Phase

Multiplying an entire quantum state by a global phase factor exp(i*alpha) has no observable physical effect, whereas the relative phase between distinct component states in a superposition directly determines physical interference patterns.

$$\Psi'(x, t) = e^{i\alpha} \Psi(x, t)$$

$$|\Psi'|^2 = |e^{i\alpha}|^2 |\Psi|^2 = |\Psi|^2$$
