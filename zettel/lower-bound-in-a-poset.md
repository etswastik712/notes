# Lower Bound in a Poset

An element of a partially ordered set that is less than or equal to every element of a designated subset.

## Links
- contrasts-with:: [[zettel/upper-bound-in-a-poset]] — A lower bound lies below or equal to every element in the subset, while an upper bound lies above or equal to every element
- generalises:: [[zettel/greatest-lower-bound]] — The greatest lower bound is defined as the maximum element within the set of all lower bounds
