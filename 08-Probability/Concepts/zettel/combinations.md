# Combinations

The number of unordered subsets of cardinality r chosen from a collection of n distinct items, evaluated by dividing the number of length-r permutations by r!.

$$\binom{n}{r} = \frac{n!}{(n - r)! r!} = \frac{n(n - 1) \dots (n - r + 1)}{r!}$$
