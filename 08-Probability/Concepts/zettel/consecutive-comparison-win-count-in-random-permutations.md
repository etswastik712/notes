# Consecutive Comparison Win Count in Random Permutations

The distribution of the number of consecutive sequential pairwise comparison victories won by an initial contestant holding a uniformly distributed random value against subsequent contestants.

$$P[X = k] = \frac{1}{k+1} - \frac{1}{k+2}$$
