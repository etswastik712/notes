# Discrete Random Variable

A random variable that takes at most countably many values (either a finite or countably infinite set) in the real numbers.

## Links
- special-case-of:: [[zettel/random-variable]] — A discrete random variable restricts the general image of a random variable to at most countably many values
- contrasts-with:: [[zettel/continuous-random-variable]] — A discrete random variable takes at most countably many values with isolated point masses, contrasting with continuous random variables defined via densities
