# Assignment 10

## Covered
Problem sheet (4 problems) on the definition of a group, abelian groups, roots of unity, the unit circle, a matrix group, permutation groups and symmetries of plane figures (Classroom: Assignment-10.pdf).

**Definitions in the sheet**
- Binary operation: a function $*:G\times G\to G$ on a nonempty set $G$, written $a*b=*(a,b)$. Saying "$*$ is a binary operation on $G$" already includes closure: $a*b\in G$ for all $a,b\in G$.
- Group: a pair $(G,*)$, $G$ nonempty, $*$ a binary operation on $G$, with
  - (G1) associativity: $(a*b)*c=a*(b*c)$ for all $a,b,c\in G$;
  - (G2) identity: there exists $e\in G$ with $e*a=a*e=a$ for all $a\in G$;
  - (G3) inverses: for every $a\in G$ there exists $b\in G$ with $a*b=b*a=e$.
  The identity $e$ is unique; for each $a$ the element $b$ in (G3) is unique and is written $a^{-1}$. The order of $G$ is $|G|$, its number of elements.
- Abelian group: $a*b=b*a$ for all $a,b\in G$; non-abelian if $a*b\ne b*a$ for some $a,b$.
- Permutation group: for a nonempty set $X$, a permutation is a bijection $f:X\to X$. $\mathrm{Sym}(X)$, the set of all permutations, is a group under composition: identity $\mathrm{id}_X$, inverse $f^{-1}$ (exists because $f$ is a bijection). Convention: $f\circ g$ means "first $g$, then $f$".
- $S_n=\mathrm{Sym}(\mathbb N_n)$ with $\mathbb N_n=\{1,\dots,n\}$ has $n!$ elements. Two-row notation: $\begin{pmatrix}1&2&3\\2&3&1\end{pmatrix}$ means $f(1)=2,\ f(2)=3,\ f(3)=1$. Cycle notation: the same permutation is $(1\ 2\ 3)$, meaning $1\mapsto2\mapsto3\mapsto1$.

**Problems and what each practises**

| Q | Problem | Practises |
|---|---|---|
| 1(a) | $\mu_4=\{1,i,-1,-i\}\subseteq\mathbb C$: write the multiplication table and use it to show $(\mu_4,\cdot)$ is an abelian group of order 4 | reading closure, identity, inverses and commutativity off a table |
| 1(b) | For $n\in\mathbb N$, $\mu_n=\{z\in\mathbb C: z^n=1\}$: show $(\mu_n,\cdot)$ is an abelian group (given: $z^n=1$ has exactly $n$ solutions $z_k=\cos\frac{2\pi k}{n}+i\sin\frac{2\pi k}{n}$, $k=0,\dots,n-1$, so $|\mu_n|=n$) | verifying (G1)-(G3) for a subset of $\mathbb C^\times$ in general, closure in particular |
| 2 | $S^1=\{z\in\mathbb C:|z|=1\}$: show $(S^1,\cdot)$ is an abelian group (hint: $|zw|=|z||w|$, $z\bar z=|z|^2$; what is $z^{-1}$ for $z\in S^1$?) | closure via $|zw|=|z||w|$; inverse via $\bar z$ |
| 3 | $T=\left\{\begin{pmatrix}1&a\\0&1\end{pmatrix}:a\in\mathbb R\right\}\subseteq M_2(\mathbb R)$ is an abelian group under matrix multiplication (matrix multiplication is given to be associative) | group inside a non-commutative operation; closure, identity, inverse, commutativity |
| 4(a) | $\Delta$ an equilateral triangle with vertices $1,2,3$ in cyclic order; a symmetry is a rigid motion carrying $\Delta$ onto itself and is determined by its action on the vertices, so it is an element of $S_3$. Show there are exactly six symmetries (identity, two rotations, three reflections) and write each as a permutation in two-row notation | counting symmetries; symmetries as permutations |
| 4(b) | Deduce the symmetries form a group under composition, equal to all of $S_3$; is it abelian? | closure under composition; $|S_3|=3!=6$; testing commutativity |
| 4(c) | Replace $\Delta$ by a non-square rectangle with vertices $1,2,3,4$, and then by a square: number of symmetries, and is the group abelian? | the same method in $S_4$ |
