# Tautology

## Covered
Source: Tautology.pdf (Classroom: Tautology).

- **Tautology:** a compound statement true for every assignment of truth values to its component statements. It is a property of logical form.
- Example: $P\lor\lnot P$ is a tautology (truth table: true for $P=T$ and $P=F$).
- Example: $(P\land Q)\Rightarrow P$ is a tautology (true in all four rows of its truth table).
- $0\ne1$ is a true statement of the number system, provable from its axioms or construction, but it is **not** a tautology: its truth comes from the number system, not from logical form.
- Any two true statements have the same truth value; in particular any true $P$ satisfies $P\sim(0\ne1)$ (same truth value).
- $5<7$ is true but not a tautology.
- Summary: **true statement $\not\Rightarrow$ tautology.**
