# Contradiction

A compound statement that evaluates to false under every possible assignment of truth values to its component variables.

$$P \land \neg P$$

## Links
- contrasts-with:: [[zettel/tautology]] — A contradiction takes a truth value of false for all valuations, whereas a tautology takes true
