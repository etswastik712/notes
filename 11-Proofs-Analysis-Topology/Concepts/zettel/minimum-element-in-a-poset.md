# Minimum Element in a Poset

An element in a partially ordered set that is less than or equal to every element in the set.

## Links
- special-case-of:: [[zettel/maximal-element-in-a-poset]] — A minimum element is comparable to all elements and forms a unique minimal element
- contrasts-with:: [[zettel/maximal-element-in-a-poset]] — A minimum precedes all elements in the poset, whereas a maximum succeeds all elements in the poset
- used-in:: [[zettel/uniqueness-of-minimum-in-a-poset]] — The antisymmetry property ensures that if a minimum element exists, it is unique
