# Compact Space

<span class="scope-extra-book">extra · book</span>

> [!syllabus] In the syllabus vs extra
> 🟡 **extra · book:** [[proofs-prems-topo.pdf#page=77|AI notes ch. 18.4]].

> [!intuition] In one picture
> Nothing can escape: any open cover can be thinned to finitely many sets.

> [!key] Definition
> $A$ is compact if every open cover has a finite subcover. Finite sets compact; $(0,1)$ not ($\{(\frac1n,1)\}$); continuous image of compact is compact; compact subsets of $\mathbb R$ are closed and bounded.

Cofinite topology on an infinite set is compact (one non-empty open set misses only finitely many points). Extreme value theorem: a continuous function on $[a,b]$ attains its max and min ($x(1-x)$ on $[0,1]$: max $\frac14$); $x$ on $(0,1)$ has none.

Used in: [[PA07 Metric and Topological Spaces]]. Related: [[Heine-Borel Theorem]] · [[Bolzano-Weierstrass Theorem]] · [[Continuous Function (Topological)]].
