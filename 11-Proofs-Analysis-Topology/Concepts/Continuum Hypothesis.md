# Continuum Hypothesis

<span class="scope-taught">taught · in syllabus</span>

> [!syllabus] In the syllabus vs extra
> 🟢 **taught:** [[Countable-Uncountable-sets.pdf#page=6|Lecture 20]].

> [!intuition] In one picture
> Is there a size strictly between the integers and the reals? ZFC cannot say.

> [!key] Definition
> CH: no set $X$ has $\aleph_0<|X|<\mathfrak c=|\mathbb R|$. Gödel (1940): not disprovable in ZFC. Cohen (1963): not provable in ZFC. **Independent.**

Posed by Cantor, 1st on Hilbert's list (1900). The lecture writes $\mathfrak c=\aleph_1$, which is CH itself (flagged in the chapter).

Used in: [[PA04 Functions and Cardinality]]. Related: [[Cardinality]] · [[Cantor's Theorem]] · [[ZFC Axioms]].
