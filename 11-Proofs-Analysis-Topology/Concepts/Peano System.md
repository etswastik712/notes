# Peano System

<span class="scope-taught">taught · in syllabus</span> <span class="scope-extra-beyond">extra · beyond</span>

> [!syllabus] In the syllabus vs extra
> 🟢 **taught:** [[L-25.pdf#page=1|Lecture 25]]: the three axioms, the example, the three non-examples, Lemma 1 (predecessor), isomorphism of Peano systems, the ZFC model.
> 🔵 **extra · beyond:** no finite Peano system; the explicit finite checks (mine).

> [!intuition] In one picture
> A start (1) and a step ($s$) that never goes back to the start and never merges two numbers, with the rule that *nothing exists except what you reach from the start by steps*. That last rule is induction.

> [!key] Definition
> A **Peano system** is $(N,1,s)$ with $s:N\to N$ and **(P1)** $s(n)\ne1$ for all $n$; **(P2)** $s$ injective; **(P3)** if $S\subseteq N$, $1\in S$ and $s(S)\subseteq S$ then $S=N$. **Lemma 1:** every $n\ne1$ is $s(m)$ for exactly one $m$ (apply (P3) to $\{1\}\cup\mathrm{Im}\,s$, then (P2)).

**Each axiom is needed:** $\{1\}$ with $s(1)=1$ breaks (P1); $\{1,2\}$ with $s(1)=s(2)=2$ breaks (P2); $\mathbb N\cup\mathbb N'$ (a disjoint second copy) breaks (P3). No finite set works: an injective $s$ on a finite set is onto, contradicting (P1). Any two Peano systems are isomorphic; ZFC gives $0=\varnothing$, $s(x)=x\cup\{x\}$ as a model.
