# Lexicographic Order

<span class="scope-taught">taught · in syllabus</span> <span class="scope-extra-book">extra · book</span>

> [!syllabus] In the syllabus vs extra
> 🟢 **taught:** the order on $\mathbb R^2$ ([[PA03 Relations Equivalence and Order]] Practice 6; pairs from the [[ordered pairs.pdf#page=1|Ordered Pairs note]]). 🟡 well-ordered pairs: Tao Exercise 8.5.12.

> [!intuition] In one picture
> Compare first coordinates; only on a tie compare second coordinates.

> [!key] Definition and theorem
> $(x,y)<(x',y')$ iff $x<x'$ or ($x=x'$ and $y<y'$). Total if both factors are; **well-ordered if both factors are** (least first coordinate, then least second). On $\mathbb N\times\mathbb N$ it has type $\omega^2$: $(2,1)$ has infinitely many predecessors. Contrast the graded order ($a+b$ first), type $\omega$, and the (partial) componentwise order.

Used in: [[PA10 Well-Ordering and Well-Ordered Pairs]]. Related: [[Well-Ordered Set]] · [[Ordered Pair]] · [[Cartesian Product]] · [[Ackermann Function]].
