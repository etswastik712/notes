# Partially Ordered Set

<span class="scope-taught">taught · in syllabus</span>

> [!syllabus] In the syllabus vs extra
> 🟢 **taught:** [[Assignment-prems_merged.pdf#page=1|Assignment 4, Q1–Q4]].

> [!intuition] In one picture
> A set with a 'before' relation in which some pairs may be incomparable.

> [!key] Definition
> Reflexive, antisymmetric, transitive. **Total** if any two elements are comparable. Examples: $(\mathbb R,\le)$ (total); divisibility; $(\mathcal P(X),\subseteq)$; product order on $\mathbb Z^2$; subspaces under inclusion.

Finite non-empty posets have maximal and minimal elements (checked on all 219 partial orders on 4 points). A finite topology is a preorder ([[Topological Space]]). A poset in which every pair has a glb and a lub is a lattice (divisors of 24: gcd, lcm).

Used in: [[PA03 Relations Equivalence and Order]]. Related: [[Extremal Elements and Bounds]] · [[Zorn's Lemma]] · [[Binary Relation]].
