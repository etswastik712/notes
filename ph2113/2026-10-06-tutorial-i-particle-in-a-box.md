# Tutorial I (6 October 2026)

## Covered
Problem set for Thursday's tutorial; no solutions posted. What each problem practises:

1. **$\langle\hat x^2\rangle$ for the $n$-th box eigenstate**, then with $\langle\hat x\rangle,\langle\hat p\rangle,\langle\hat p^2\rangle$ compute $\Delta x\,\Delta p$ for state $n$. Practises: expectation integrals of $\sin^2(n\pi x/a)$, and checking the uncertainty relation $\Delta x\Delta p\ge\hbar/2$.
2. **State $\psi=\tfrac1{\sqrt3}[\psi_1+\psi_2+\psi_3]$**: possible energy outcomes and $\langle E\rangle$. Practises: Born rule on an energy superposition, $\langle E\rangle=\sum|c_n|^2E_n$.
3. **State $\psi(x,0)=\tfrac1{\sqrt2}[\psi_1+\psi_2]$**: sketch at $t=0$ and at $t=\pi\hbar/2E_1$, $\pi\hbar/E_1$, $2\pi\hbar/E_1$. Practises: relative-phase evolution $e^{-i(E_2-E_1)t/\hbar}$ and how $|\Psi|^2$ sloshes (compare Midsem Q3).
4. **Prove**: if $V(x)$ is symmetric, eigenfunctions are symmetric or antisymmetric. Practises: parity operator commuting with $\hat H$.
5. **Prove $E\ge V_{\min}$ by contradiction**: assume $E<V_{\min}$, show $\psi''/\psi>0$ wherever $\psi\neq0$; pick $x_0$ with $\psi(x_0)>0$; if $\psi'(x_0)\ge0$, $\psi$ keeps growing for $x>x_0$; if $\psi'(x_0)<0$, the same as $x\to-\infty$. Is this a valid wavefunction? Practises: sign/convexity argument and normalisability.
