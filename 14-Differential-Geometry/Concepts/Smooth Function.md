# Smooth Function

<span class="scope-taught">taught · in syllabus</span>

> [!syllabus] In the syllabus vs extra
> 🟢 **taught:** [[mt3184-differential-geometry-and-lie-groups/2026-08-07-august-3-7|week 1]] (smooth maps); HW2 Q1.

> [!intuition] In one picture
> A function whose coordinate expression is smooth in every chart: calculus-friendly, independent of the coordinates chosen.

> [!key] Definition
> $f:M\to\mathbb R$ is smooth if $f\circ\varphi^{-1}$ is smooth for every smooth chart $(U,\varphi)$. $C^\infty(M)$ is a ring, and an $\mathbb R$-algebra; vector fields act on it as derivations ([[DM10 Vector Fields and Lie Brackets]]).

Coordinate functions $x^i:U\to\mathbb R$ of a chart are smooth on $U$. Bump functions and partitions of unity are smooth functions with controlled supports.

Used in: [[DM02 Smooth Maps and Partitions of Unity]]. Related: [[Smooth Map]] · [[Bump Function]] · [[Partition of Unity]].
