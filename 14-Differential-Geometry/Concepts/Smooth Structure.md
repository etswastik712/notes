# Smooth Structure

<span class="scope-taught">taught · in syllabus</span>

> [!syllabus] In the syllabus vs extra
> 🟢 **taught:** [[mt3184-differential-geometry-and-lie-groups/2026-08-07-hw1|HW1]] Q1, Q4.

> [!intuition] In one picture
> The extra layer that says which functions and maps count as smooth: it is chosen, not forced by the topology.

> [!key] Definition
> A **smooth structure** on a topological manifold $M$ is a maximal smooth atlas. The same $M$ can have several (distinct; sometimes non-diffeomorphic: [[Exotic Smooth Structure]]).

Example: the chart $x\mapsto x^3$ gives a second structure on $\mathbb R$ (incompatible with the identity chart: $y^{1/3}$ is not smooth) which is diffeomorphic to the standard one. Uncountably many structures via $F_s(x)=|x|^{s-1}x$ ([[DM01 Smooth Manifolds]] §5).

Used in: [[DM01 Smooth Manifolds]]. Related: [[Smooth Atlas]] · [[Smooth Manifold]] · [[Exotic Smooth Structure]].
