# Smooth Map Between Smooth Manifolds

A continuous map between two smooth manifolds that is smooth in local coordinates near every point. At a point p in the domain, the composition of the map with the inverse domain chart and target chart must yield a smooth Euclidean function.

$$\psi \circ F \circ \varphi^{-1} : \varphi(U \cap F^{-1}(V)) \to \psi(V)$$
