# Sard's Theorem

<span class="scope-extra-book">extra · book</span>

> [!syllabus] In the syllabus vs extra
> 🟡 **extra · book:** [[John M. Lee - Introduction to Smooth Manifolds.pdf#page=147|Lee Thm 6.10, p. 129]], [[John M. Lee - Introduction to Smooth Manifolds.pdf#page=149|Cor. 6.11, p. 131]]; Milnor §3 (stated, not proved in DM07).

> [!intuition] In one picture
> Critical values are rare: almost every level of a smooth map is a regular level, hence a manifold.

> [!key] Definition
> For a smooth map $F:M\to N$ the set of critical values has measure zero in $N$; so regular values are dense. Needs $C^\infty$ (or $C^k$, $k\ge\max(m-n+1,1)$).

$f=x^3-3x$: critical values $\pm2$ only (all $5000$ random levels regular). Critical *points* may be numerous even though critical *values* are null. Makes the [[Regular Level Set Theorem]] apply to almost every level.

Used in: [[DM07 Sard Whitney and Transversality]]. Related: [[Regular Value]] · [[Set of Measure Zero]] · [[Regular Level Set Theorem]].
