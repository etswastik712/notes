**Vector fields (DG9, DG10)**
- A vector field on $M$ is a smooth map $X: M \to TM$ with $\pi\circ X = \mathrm{id}_M$, i.e. $X(p)\in T_pM$. For a submanifold $S\subset\mathbb R^3$ this is a smooth map $S\to\mathbb R^3$ with $v(p)\in T_pS$.
- Tangent bundle: $TM=\coprod_{p\in M}T_pM$. On an open $U\subset\mathbb R^n$ it is $U\times\mathbb R^n$. Charts $\varphi$ of an atlas of $M$ induce charts $\tilde\varphi$ on $TM$. $TM$ gets the topology making each $\tilde\varphi$ a homeomorphism, and $\pi: TM\to M$ is the projection.
- Local coordinates: for a chart $(U,\varphi=(x^1,\dots,x^n))$, $X=\sum_i X^i\,\partial/\partial x^i$ on $U$. $X$ is smooth iff the component functions $X^i$ are smooth. The coordinate vector fields $\partial/\partial x^i$ are defined on $U$.
- $\mathfrak X(M)$ is the set of vector fields on $M$. It is a module over $C^\infty(M)$.
- A local frame for $M$ on $U$ is a tuple of vector fields $E_1,\dots,E_n$ such that $E_1(p),\dots,E_n(p)$ is a basis of $T_pM$ for all $p\in U$. Example: a coordinate frame.
- Lie groups have global frames. The only spheres with global frames are $S^1$, $S^3$ (and $S^7$ is not mentioned legibly; the slide reads "$S^1$ and $S^3$").
- Vector fields as derivations: for $X\in\mathfrak X(M)$ and $f\in C^\infty(M)$, define $(Xf)(p)=X_pf$. Claim: $Xf\in C^\infty(M)$, $X$ is linear over $\mathbb R$, and $X(fg)=fXg+gXf$ (Leibniz rule). Without smoothness of $X$, $Xf$ need not be smooth.
- Prop 8.14: for a rough vector field $X: M\to TM$ with $\pi\circ X=\mathrm{id}$, the following are equivalent: (a) $X$ is smooth; (b) $Xf\in C^\infty(M)$ for all $f\in C^\infty(M)$; (c) for every open $U\subset M$ and $f\in C^\infty(U)$, $Xf\in C^\infty(U)$. Proof pattern (a)⇒(b): in a chart, $Xf=\sum X^i\,\partial f/\partial x^i$, both factors smooth. (c)⇒(a)/(b)⇒(a) uses extension of a coordinate function by a bump function on a neighbourhood $N$ of $p$ with $\bar N\subset U$, to show each $X^i$ is smooth.
- Prop (DG10): a derivation $D: C^\infty(M)\to C^\infty(M)$ (linear over $\mathbb R$, Leibniz) is of the form $D f = Xf$ for some $X\in\mathfrak X(M)$. Proof: define $X_p f = (Df)(p)$; this is a derivation at $p$, so $X_p\in T_pM$; $X$ is smooth since $Xf$ is smooth for each $f$.
- $F$-related fields: for a smooth $F: M\to N$, $X\in\mathfrak X(M)$ and $Y\in\mathfrak X(N)$ are $F$-related if $dF_p(X_p)=Y_{F(p)}$ for all $p$. $dF$ does not in general push a field on $M$ forward to a field on $N$.
- Prop 8.19: if $F: M\to N$ is a diffeomorphism, every $X\in\mathfrak X(M)$ has a unique $Y\in\mathfrak X(N)$ that is $F$-related to it, namely $Y_q=dF_{F^{-1}(q)}(X_{F^{-1}(q)})$, which is smooth.
- Prop 8.22: let $S\subset M$ be a submanifold and $X\in\mathfrak X(M)$. Then $X$ is tangent to $S$ if and only if $(Xf)|_S=0$ whenever $f|_S\equiv0$.
- Prop 5.37: $T_pS=\{v\in T_pM : vf=0 \text{ whenever } f|_S\equiv0\}$. Proof of ⊆: if $v\in T_pS$, $vf=d\iota_p(v')f=v'(f\circ\iota)=0$. Converse (set as HW, using a slice chart and a bump function): in a slice chart where $S=\{x^{k+1}=\dots=x^n=0\}$, for $v=\sum v^i\partial_i$ take $f=x^j$ (times a bump function) with $j>k$, giving $v^j=0$.

**Lie groups (DG10, DG11)**
- A Lie group is a smooth manifold that is also a group such that multiplication $m: G\times G\to G$, $(g,h)\mapsto gh$, and inversion $i: G\to G$, $g\mapsto g^{-1}$, are smooth.
- Examples: $(\mathbb R^n,+)$; $M(n,\mathbb R)$ under addition; $GL(n,\mathbb R)$ (open in $M(n,\mathbb R)$, inversion smooth by the cofactor formula $A^{-1}=\mathrm{adj}(A)/\det A$); $SL(n,\mathbb R)=\{\det=1\}$, an embedded Lie subgroup; $GL(n,\mathbb C)$, of dimension $2n^2$; $\mathbb C^*\cong GL(1,\mathbb C)$; $S^1\subset\mathbb C^*$; products $G_1\times\dots\times G_k$ of Lie groups, e.g. the torus $T^n=S^1\times\dots\times S^1$.
- Lie group homomorphism: a smooth group homomorphism $F: G\to H$. A Lie group isomorphism is a diffeomorphism that is a homomorphism. Cor 7.6: a smooth bijective group homomorphism is an isomorphism (via constant rank, see below).
- Examples of homomorphisms: $\exp:\mathbb R\to\mathbb R^*$, $t\mapsto e^t$ (not surjective onto $\mathbb R^*$; an isomorphism onto $\mathbb R_{>0}$ with inverse $\log$); $\varepsilon:\mathbb R\to S^1$, $t\mapsto e^{2\pi it}$, with kernel $\mathbb Z$; $\mathbb C\to\mathbb C^*$, $z\mapsto e^z$, with kernel $2\pi i\mathbb Z$; $\det: M(n,\mathbb R)\to\mathbb R$ is smooth but not a homomorphism for $+$; $\det: GL(n,\mathbb R)\to\mathbb R^*$ is a homomorphism with kernel $SL(n,\mathbb R)$; $c_g: G\to G$, $h\mapsto ghg^{-1}$ is an isomorphism.
- Left translation $L_g: G\to G$, $h\mapsto gh$, is a diffeomorphism (smooth as $m\circ(g,\cdot)$, inverse $L_{g^{-1}}$).
- Thm 7.5: every Lie group homomorphism $F: G\to H$ has constant rank. Proof: $F\circ L_g=L_{F(g)}\circ F$, so $dF_g\circ d(L_g)_e = d(L_{F(g)})_e\circ dF_e$; the maps $dL$ are isomorphisms, so $\mathrm{rank}\,dF_g=\mathrm{rank}\,dF_e$.

**Constant rank theorems (DG11)**
- Thm 4.14 (Global Rank Theorem): let $F: M^m\to N^n$ be smooth of constant rank $r$. (a) $F$ surjective ⇒ $F$ is a submersion ($r=n$). (b) $F$ injective ⇒ $F$ is an immersion ($r=m$). (c) $F$ bijective ⇒ $F$ is a diffeomorphism ($r=m=n$).
- Thm 4.12 (Rank Theorem): for $F$ of constant rank $r$ and $p\in M$ there are charts $(U,\varphi)$ centred at $p$ and $(V,\psi)$ centred at $F(p)$ with $F(U)\subset V$ and $\psi\circ F\circ\varphi^{-1}(x^1,\dots,x^m)=(x^1,\dots,x^r,0,\dots,0)$.
- Linear-algebra model: for a linear map $A:\mathbb R^m\to\mathbb R^n$ of rank $r$ there are bases in which $A=\begin{pmatrix}I_r&0\\0&0\end{pmatrix}$ (extend a basis of $\ker A$ ($v_{r+1},\dots,v_m$) to a basis; the images of the remaining basis vectors are linearly independent; extend them to a basis of $\mathbb R^n$).
- Nowhere dense: $A\subset X$ is nowhere dense if $\mathrm{int}(\bar A)=\emptyset$. Examples: $\mathbb Q\subset\mathbb R$ is not nowhere dense; the Cantor set is; $\mathbb R^k\times\{0\}\subset\mathbb R^n$ (for $k<n$) is.
- Baire Category Theorem: if $X$ is a locally compact Hausdorff space or a complete metric space, a countable union of nowhere dense sets has empty interior. (A countable union of nowhere dense sets need not itself be nowhere dense.)
- Proof of the global rank theorem for the surjective case (outline): if $r<n$, the rank theorem shows $F(\bar B_p)$ is closed and nowhere dense in $N$ for a suitable precompact neighbourhood $B_p$ of each $p$; countably many such $B_p$ cover $M$ (second countable), so $F(M)=N$ would be a countable union of nowhere dense sets, contradicting Baire.
