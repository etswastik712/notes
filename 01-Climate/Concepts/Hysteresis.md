# Hysteresis

<span class="scope-taught">taught · in syllabus</span>

> [!syllabus] In the syllabus vs extra
> 🟢 **taught:** Joy O6 deck frames 21–22; Daisyworld tutorial Run 5 (2026)

> [!intuition] In one picture
> Where the system is depends on how it got there: the same forcing, two states.

> [!key] Definition
> With two stable branches over a range of forcing, increasing the forcing past the edge of one branch makes the state jump; reversing the forcing leaves it on the other branch until a different edge. Daisyworld all land: daisies die at L ≈ 1.63 and return at 1.17; AMOC box model: collapse at F_max, return only at F < 0. Transient version: forcing faster than the response gives path-dependent states.

Same structure as Argha's snowball multiple equilibria.
